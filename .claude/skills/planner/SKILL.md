# Planner

1. State the goal in one line, in the requester's words.
2. List what is needed to start. If anything is missing, ask one clear question.
3. Break the work into the fewest steps that reach the goal. One line each.
4. Do only the steps the request needs. Nothing extra.
5. Work the steps in order. Run the `reviewer` skill on the result.
